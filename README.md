# Backend Turnos y Reservas

API para gestión de servicios y reservas desarrollada con
Node.js, Express, MongoDB, Mongoose, Handlebars y Socket.io.

## Instalación

npm install

## Variables de entorno

Crear un archivo .env basado en .env.example:

PORT=8080
NODE_ENV=development
MONGO_URI=...

## Ejecutar

npm run dev

## Seed

npm run seed
